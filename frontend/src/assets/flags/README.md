# Locale flags

Three local 4:3 SVGs from [flag-icons](https://github.com/lipis/flag-icons), commit `ac7e0eb3259eb62aa6100c435607e2fe03896a97`.

- `us.svg`: `flags/4x3/us.svg`
- `hk.svg`: `flags/4x3/hk.svg`
- `cn.svg`: `flags/4x3/cn.svg`

Flag geometry is unchanged. The MIT license is included in `LICENSE` and in each SVG comment so bundled copies retain the notice. Vite bundles these static assets; the language selector does not contact an external image service or depend on OS emoji fonts.
